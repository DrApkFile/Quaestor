## D15 — legacy M4 records only

Opening/close anchors in M4 hash plaintext records. Publish owner-hybrid-signed mappings {book,kind,anchoredSha3,ciphertextSha3} as keccak256("quaestor:legacy-map"). The auditor verifies the book owner's signature, fetches and hashes ciphertext, decrypts it, and verifies plaintext SHA3 against the immutable original Books anchor. Test wrong plaintext/anchor and non-owner mapping refusal.

All new records anchor ciphertext SHA3, including opening and close; the raw ML-DSA close signature covers that ciphertext hash. No Books contract change. Record that low-entropy plaintext hashes leak guessable records: M4 opening balances are demo data and must be treated as disclosed. Close records include proof bytes but ciphertext anchoring is still required going forward.
