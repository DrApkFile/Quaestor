# @quaestor/web

Normal web app (Vite + React; not a PWA). Screens: Business (books, grants, close period), Pay, Auditor (open a granted period, verdicts), Public check.
All sealing and opening happens here, in the browser. Circuit files are self-hosted in `public/circuits/` (fetched by `scripts/vendor-gloam.sh`, not committed).
Built in milestones M6–M7.
